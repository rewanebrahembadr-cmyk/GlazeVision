# P2 — Classical machine learning

**Difficulty** Basic

**Course** Machine Learning with Python, sessions 1 and 3–5

## Goal

Classical machine learning

## Inputs

Prepared samples, label map and split from P1

## Tasks

- [ ] Fit majority-class baseline and log per-class metrics.
- [ ] Compare logistic regression, KNN, decision tree, random forest and SVM.
- [ ] Use validation for selection and inspect mistakes with the review CSV.
- [ ] Summarize limitations and confusion between finish classes.

## Outputs

- `src/glazevision/tabular_models.py`
- `notebooks/02_classical_ml.ipynb`
- `reports/results.csv`

## Definition of done

Results include the baseline, per-class metrics and reviewed mistakes on held-out groups.

## Bonus

Use group-aware GridSearchCV within training and chart all team results.
